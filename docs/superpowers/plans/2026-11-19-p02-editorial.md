# P02 — Discovery e geração editorial: Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Passos com checkbox; TDD (teste falha antes).

**Goal:** tema → fontes guardadas (snapshot) → roteiro restrito a fatos das fontes → checagem factual determinística → metadados, tudo persistido e acionável por `/studio`.

**Architecture:** mesma Clean Architecture da P00/P01. Lógica factual pura em `domain/`; fontes, LLM, repositórios e custo em `application/` (portas) e `adapters/`. O gate real é a checagem determinística; a revisão por LLM é só consultiva (spec §5.12–13).

**Tech Stack:** Python 3.12, Pydantic v2, psycopg 3, httpx (já no projeto), stdlib `html.parser`.

**Spec:** `docs/superpowers/specs/2026-11-19-faceless-studio-design.md` (P02, decisões 12 e 13).

## Global Constraints
- Fatos só de fontes oficiais guardadas; evento encerrado → texto no passado.
- Só modelos `:free`; `MAX_COST_USD_PER_VIDEO` padrão 0; teto mensal US$ 15; `check_cost` antes de toda chamada de modelo.
- Nunca imprimir segredos; IDs `uuid4().hex`; regra de dependência da Clean Architecture (teste de arquitetura).
- `/videos` e o workflow V2 continuam inalterados.
- Reprovação factual bloqueia `FACT_CHECKED`; override humano exige motivo não vazio e fica registrado.

## Review Focus
1. Número inventado, ou fora da fonte citada, reprova; formatos equivalentes (`3.600`, `3,600`, `três mil e seiscentos`, `1,5 mil`) aprovam.
2. SSRF: URL fora da allowlist, `file://`, host que resolve para IP privado/loopback, redirect para fora da allowlist — tudo recusado.
3. Página enorme ou binária: corte por tamanho e recusa de tipo, sem estourar memória.
4. Duas execuções de roteiro/checagem no mesmo vídeo: uma só transição vence; versões do `Script` incrementam sem colisão.
5. Resposta do LLM fora do JSON esperado, com cena sem narração ou `claim_ids` inexistentes: recusada, nada persistido.
6. Override sem motivo (vazio/espaços): recusado.

**Interfaces — Produces:**
- `normalize(text: str) -> str` (minúsculas, sem acentos, espaços colapsados)
- `numbers_in(text: str) -> set[str]` — valores canônicos: separador de milhar removido (`3.600`/`3,600` → `3600`), decimal com ponto (`1,5` → `1.5`), `N mil` → ×1000, números por extenso pt-BR (0–999, `mil`) → dígitos

- `check_narration(narration: str, source_texts: list[str], allow_names: frozenset[str] = frozenset()) -> list[Unsupported]`

Testes (nomes): `test_digits_and_words_equal`, `test_thousand_separators_pt_and_en`, `test_decimal_and_mil`, `test_invented_number_is_flagged`, `test_number_supported_by_source`, `test_proper_noun_not_in_source_is_flagged`, `test_sentence_start_capital_ignored`, `test_hyphenated_name_split`, `test_allow_names`, `test_accents_folded`, `test_date_21_10`.

### Task 3: Portas, custo e casos de uso
**Files:** Modify `application/ports.py`; Create `application/editorial.py`; Test `tests/test_editorial.py` (com fakes, sem banco)
**Interfaces — Produces (portas):** `SourceFetcher.fetch(url) -> FetchedPage(text, final_url)`; `SnapshotRepository.add(video_id, url, text) -> SourceSnapshot` / `list(video_id)`; `ScriptRepository.save(video_id, narrations_text, scenes, claim_ids) -> Script` (versão +1 atômica) / `latest(video_id)` / `scenes(video_id)`; `FactCheckRepository.save(video_id, report)`; `UsageRepository.record(video_id, entry)` / `spent_video(video_id) -> float` / `spent_month() -> float`.
