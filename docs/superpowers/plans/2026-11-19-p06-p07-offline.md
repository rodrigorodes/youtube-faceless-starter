# P06–P07 offline implementation plan

**Goal:** Add independently testable recovery primitives and persisted analytics without touching reserved HTTP files.
**Architecture:** Application services depend on Postgres adapters; analytics reports aggregate daily records in SQL. Existing render recovery remains the source of render execution.
**Tech Stack:** Python, psycopg, PostgreSQL, pytest.
**Spec:** `docs/superpowers/specs/2026-11-19-faceless-studio-design.md`.

## Constraints
- No external calls, real uploads, changes to main.py or api/routes.py.
- HTTP wiring, live collection, real-data acceptance, and user credentials are separate follow-up work.
- Never conflate an absent metric with zero; no recommendation from a small sample.

## Tasks
1. P06: test and implement bounded transient-only retry with jitter, and transactional step-run recording and same-input success lookup; document limitations.
2. P07: test and implement validated daily upsert and aggregate weekly report, including provenance and small-sample behavior.
3. Run focused tests and full suite, record evidence and remaining integration.
