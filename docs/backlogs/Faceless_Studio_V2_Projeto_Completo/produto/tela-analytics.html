Zero não é o mesmo que “sem dado”: quando a API não devolve o valor, o estado é ainda não disponível — nunca 0% nem estimativa apresentada como medição.

Insights

Observação é o que o dado mostra; hipótese é o que ainda não foi comprovado. Os dois são rótulos diferentes, com evidência e nível de confiança.

Recomendações

Uma recomendação sugere, não decide. Nada é reconfigurado sozinho: aplicar cria uma nova versão do perfil do canal e só vale depois da sua aprovação — e você pode recusar sem efeito.

Exemplo ilustrativo: “manter ~8 min no próximo vídeo do pilar de finanças”.

Honestidade do dado

CTR e retenção dependem de escopos e permissão da API do canal. Quando o dado não vem, mostramos ainda não disponível; nunca preenchemos com 0 nem com estimativa disfarçada de medição.
