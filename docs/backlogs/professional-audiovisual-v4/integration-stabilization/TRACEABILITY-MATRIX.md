- `MODEL_ONLY`: Pure domain/application types or functions tested only in isolation with no real production consumer.
- `MOCK_ONLY`: Tested with fakes/mocks/synthetic constants/magic-byte stubs without real I/O, DB concurrency, FFmpeg decode, or real provider execution.

- `VERIFIED`: Wired to real consumer + positive/negative tests + observed evidence meeting applicable gates (subject to final full-suite confirmation in `REC-04.03`).
