# Contratos propostos (não APIs existentes)
ProviderRequest: run_id, capability, idempotency_key, input, constraints, budget, config_version. ProviderResult: asset_ref, actual_cost, provenance, capabilities_used, warnings, duration_ticks. Erros tipados: transient, permanent, unsupported, budget_exceeded, license_unknown. Registry resolve capability + policy + budget; fallback registrado e reavaliado.
AssetRef: id, content_hash, media_type, uri interna, format, duration_ticks, license_evidence, provider/model/version. Não expor segredos.
RenderPlan: preservar schema atual; extensão versionada para tracks, z_order, start_tick, duration_ticks, transforms, keyframes, transitions, audio events. Intervalos [start,end), ordem estável, arredondamento explícito; crossfade não altera duração declarada sem política explícita. Compilador retorna spec ou erro de capability. QA issue: code, severity, scene/shot/asset, interval, evidence, suggested_action. Invalidação via grafo de dependências e fingerprints; alterações de voz podem afetar cenas posteriores. Validar contratos reais na fase 00.
