# Arquitetura
Experience (Studio, storyboard, timeline) → Intelligence (Finder, roteiro, direção, identidade) → Production (coordenação, orçamento, checkpoint) → Media (registry, adapters, assets) → Composition (RenderPlan, ticks, compiler) → Execution (FFmpeg, QA, publisher). Fluxo lógico, não dependência obrigatória entre módulos. Domínio puro; aplicação usa portas; adapters implementam portas; composition root injeta dependências. n8n orquestra externamente sem duplicar estado ou regras. Infra transversal: persistência, cache, licenças, credenciais, custos, observabilidade. Ver diagrams/.
